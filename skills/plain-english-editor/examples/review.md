# Example: review

The user asked: "Tell me what is useful or unnecessary in this project update."

## Source

> Project update: We are making great progress. The data import finished on Tuesday. We
> imported 4,200 records. Overall, things are going well and the team is working hard. The next
> step is testing the reports, which should start Monday. In summary, the import is done and
> testing is next.

## Review

**Keep:**

- "The data import finished on Tuesday." It states a dated result.
- "We imported 4,200 records." It gives a concrete count.

**Change:**

- "The next step is testing the reports, which should start Monday." Replace "Monday" with the
  exact date so the update stays accurate after this week.

**Remove:**

- "We are making great progress." The specific facts already show progress.
- "Overall, things are going well and the team is working hard." It adds no fact.
- "In summary, the import is done and testing is next." It repeats earlier sentences.

## Revised

> The data import finished on Tuesday, September 29. We imported 4,200 records. Report testing
> starts Monday, October 5.

## What this example shows

- Each issue is named once, with one suggested change.
- Praise and summary sentences are removed because they add no fact.
