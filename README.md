# Plain English Editor

*Write it once. Have it understood the first time.*

Paste in an email, a doc, or a process write-up. Get it back shorter and clearer, with every
fact still in it. The filler, jargon, and "just circling back" are gone.

- Cuts filler openings, recaps, and summary sentences
- Spells out abbreviations and explains technical terms at first use
- Turns automation write-ups into Trigger, Inputs, What happens, and Outputs
- Reviews drafts with Keep, Change, and Remove labels
- Labels missing facts as unknown instead of guessing

## Install

```
claude plugin marketplace add RachaelQuisel/plain-english-editor
claude plugin install plain-english-editor@plain-english-editor
```

## Use

Run `/plain-english-editor` with your text, or ask Claude to "make this plain English."
Worked examples live in `skills/plain-english-editor/examples/`.

## What data it sends

None. The plugin is a skill file and examples. It has no scripts, hooks, or servers.
