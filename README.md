# Plain English Editor

Rewrite or review text so the reader can understand it. The plugin preserves facts and removes filler, repeated claims, and unexplained technical terms.

Start with `/plain-english-editor:plain-english-editor`. If details are missing, it asks for the text, reader, and destination or output. It waits for answers and remembers them. If your request is complete, it starts the work.

- Receive revised text or focused feedback.
- Keep the requested email, message, or document format.
- Explain processes with Trigger, Inputs, What happens, and Outputs.
- Clarify unclear facts before rewriting the affected passage.

## Install

```text
claude plugin marketplace add RachaelQuisel/plain-english-editor
claude plugin install plain-english-editor@plain-english-editor
```

Read [how it works](Plain-English-Editor-HowItWorks-2026-10-03.md) and [worked examples](skills/plain-english-editor/examples/).

## Data and permissions

The plugin reads the text you supply in your session. The host processes it under its own terms and settings. The package includes instructions and examples without a publisher-operated service. It does not request sending or publishing. Saving a document requires your request.
