## Trigger

- The user asks to rewrite or review text in plain English.

## Inputs

- The source text supplies the facts and wording.
- The reader and destination determine the format.
- The user chooses revised text or feedback.

## What happens

1. The plugin acknowledges the request. It asks up to three questions about missing text, the reader, and the destination or requested output.
2. It waits for required answers. It retains supplied details and responds to corrections. If the request is complete, it starts the work.
3. It asks about an unclear material fact before rewriting that passage. It labels a missing fact as unknown.
4. It preserves facts, exact names, commands, and required syntax. It removes filler and repeated claims. It explains necessary technical terms.
5. For an automation or process, it uses Trigger, Inputs, What happens, and Outputs. For other content, it keeps the requested format.
6. For a review, it uses Keep, Change, and Remove only where useful. For a rewrite, it returns the finished text.
7. It checks meaning and clarity before responding. A requested revision uses the latest answers.

## Outputs

- Revised text or a focused review in the current chat.
- A saved document only when saving is requested. The plugin does not send or publish the text.
